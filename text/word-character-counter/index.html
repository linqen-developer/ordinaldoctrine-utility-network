How to use it

  1. Type or paste text into the text area.
  2. Read the live counts.
  3. Copy the text or clear it when finished.

Counting method

  • Words: the browser's built-in word segmenter is used when available. Apostrophes within words normally stay together; hyphens may form boundaries; standalone emoji do not count as words; non-Latin scripts use the browser's language-independent segmentation.
  • Word fallback: Unicode letter or number groups count as words, with internal apostrophes and hyphens kept together. A continuous script with no spaces may count as one word.
  • Characters: visible grapheme clusters are counted when supported, so a joined emoji can count as one. The fallback counts Unicode code points, which can count combining sequences differently.
  • Lines: any non-empty input has at least one line. Each line break adds one. Paragraphs: non-empty blocks separated by one or more blank lines.

Other applications may use different counting rules. This tool does not claim one universal linguistic count.

Example

“Don't re-enter 🚀” has two words with the fallback method; the standalone emoji is not a word.
