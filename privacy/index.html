Privacy

Your tool input stays in your browser.

Input and results

Dates, numbers, text and supported images entered into these utilities are processed locally. Site code does not transmit them, add them to a URL, save them in browser storage, log them or use them for analytics or training.

Cookies and storage

This static utility site does not set cookies and does not use local storage, session storage or a browser database. Reloading or closing a page clears the current tool state unless the browser itself restores a page.

Page requests

As with any website, requesting a page or static file sends standard connection information to the hosting service. The utility input is not part of those requests. The site loads no remote fonts, scripts, trackers or advertisements.

Clipboard and downloads

A copy button writes only the visible result or text you choose to copy to your device clipboard. Image downloads use a temporary browser-local object URL and are released when the page closes or the result changes. Nothing is sent to this site.

Questions

Use the contact page. Do not include private tool input in a problem report.
