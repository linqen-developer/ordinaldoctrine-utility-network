How to use it

  1. Choose one static JPEG, PNG or WebP photo.
  2. Select 1 MB, 500 KB, 200 KB, 100 KB or enter a custom limit from 10 KB through 10 MB.
  3. Compress, review the measured output and any dimension or metadata change, then download.

How it works

  • The image container and declared dimensions are checked before browser decoding, then the image is decoded and re-encoded locally. Image content is not uploaded, logged by this site or used for training.
  • 1 KB means 1,000 bytes and 1 MB means 1,000,000 bytes. Re-encoded files use 0.5% headroom and must measure at or below that operational target before download is enabled.
  • JPEG and WebP are tested from 92% through a 70% encoder-quality floor. If needed, dimensions reduce in 10% steps to a 640 px long-edge floor. The first compliant result keeps the largest tested dimensions and quality.
  • PNG uses a browser re-encode that keeps alpha but can change dimensions, pixel representation, metadata and color-profile information. It is not silently converted to JPEG. An original already below the hard limit is returned unchanged.
  • The result reports inspected EXIF, ICC, alpha and color-model outcomes. Re-encoding can also remove XMP, IPTC, comments, PNG text, gamma and chromaticity tags. Every changed dimension, format and measured byte count is shown before download.

Limits

Files are limited to 50 MB, 50 megapixels and 16,384 px on either axis for validation and unchanged-original results. Re-encoding is limited to 12 megapixels to keep peak memory bounded. Animated images, SVG, HEIC, GIF, TIFF, RAW and PDF are not supported. Some targets cannot be met within the default quality and size floors; the tool reports that honestly instead of rounding an oversized result down.

Verified browser scope: current desktop Chrome, Edge and Firefox on Windows. Other browsers must support local image-bitmap decoding and same-format canvas export; unverified Safari, iOS and physical mobile environments are not claimed as tested.
