How to use it

  1. Enter a decimal value.
  2. Choose explicit from and to units, or swap them.
  3. Choose the displayed significant digits and copy the result.

Conversion basis

  • All values pass through metres using fixed factors: 1 inch = 0.0254 metre, 1 foot = 0.3048 metre, 1 yard = 0.9144 metre and 1 international mile = 1,609.344 metres.
  • Metric factors are 1 millimetre = 0.001 metre, 1 centimetre = 0.01 metre and 1 kilometre = 1,000 metres.
  • Display rounding never changes the full internal conversion value. A repeating reciprocal in the conversion basis is shown with up to 15 significant digits.
  • Unit names follow the visible quantity: 1 and −1 use the singular form; zero and other values use the plural form. If rounding displays a target value as 1, its visible unit name is singular while the full internal value remains unchanged.
  • Negative values are accepted as mathematical conversions. Exponent notation, commas, infinity and values outside finite numeric range are rejected and retained for correction.

Examples

1 metre = 100 centimetres.

1 international mile = 1.609344 kilometres.
